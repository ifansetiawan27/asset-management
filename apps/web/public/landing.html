Cara Kerja

Siap digunakan dalam 4 langkah

Tidak perlu setup Keycloak atau infrastruktur tambahan. Backend sudah terhubung ke Supabase dan siap menerima pendaftaran pertama Anda.

1
Daftar sebagai Super Admin
Buka halaman /register dan daftarkan email pribadi Anda. Karena Anda adalah pengguna ber-password pertama di sistem, akun Anda otomatis mendapatkan peran Super Admin dengan akses penuh. Tenant default dan 7 role sistem dibuat secara otomatis (idempotent).
2
Tambah Tim & Tetapkan Peran
Login ke dashboard, buka menu Pengguna. Bagikan link /register ke anggota tim untuk self-registration. Pengguna baru mendapat peran Employee secara default—Super Admin dapat memperbarui peran mereka dari halaman pengguna sesuai tanggung jawab di organisasi.
3
Input Data Aset Organisasi
Mulai dari modul Katalog Aset—buat kategori, tambah vendor, dan daftarkan setiap aset dengan detail lengkap (harga perolehan, nomor seri, lokasi, departemen). Generate QR Code untuk dipasang pada unit fisik, siap untuk scanning di lapangan.
4
Monitor & Kelola Secara Real-time
Seluruh tim kini berkolaborasi: Teknisi melaporkan kerusakan dan mengerjakan work order, Auditor memverifikasi keberadaan fisik, Manager menyetujui transfer & peminjaman, dan pimpinan memantau dashboard nilai & kondisi aset secara real-time.
Peran & Akses

RBAC 7 peran untuk setiap tingkatan

Setiap peran memiliki permission granular yang disesuaikan per-tenant. Kontrol akses yang presisi memastikan hanya yang berwenang yang dapat melakukan tindakan tertentu.

👑
Super Admin
Akses penuh ke seluruh sistem—kelola tenant, pengguna, role, dan semua modul.
🛡️
Asset Administrator
Kelola katalog aset, penugasan, approval peminjaman, dan laporan.
🛒
Procurement
Input aset baru, kelola vendor & pengadaan, buat tiket maintenance.
🔧
Teknisi
Kerjakan work order, update status perbaikan, dan catat suku cadang.
🔍
Auditor
Lakukan audit fisik, verifikasi keberadaan aset, dan rekonsiliasi laporan.
👔
Department Manager
Setujui/tolak transfer, peminjaman, dan disposal aset di departemennya.
👤
Employee
Lihat daftar aset yang tersedia, ajukan peminjaman, dan buat tiket masalah.
Keamanan & Arsitektur

Dirancang untuk keamanan data tingkat enterprise

🔒
Row-Level Security PostgreSQL
Data setiap tenant diisolasi secara kriptografis di level database. Query tanpa konteks tenant tidak akan mengembalikan baris apa pun—FORCE ROW LEVEL SECURITY aktif.
🎟️
JWT HS256 Lokal
Token ditandatangani API sendiri dengan JWT_SECRET acak ≥32 karakter. Tidak ada ketergantungan pada Keycloak atau pihak ketiga. Masa berlaku 8 jam.
🔐
bcrypt Password Hashing
Password di-hash dengan bcrypt 10 rounds. Kolom password_hash bertanda select:false—hash tidak pernah bocor dalam respons API normal.
🏗️
NestJS 11 + Next.js 16 + Supabase
Backend NestJS 11 dengan Express 5, migrasi TypeORM terstruktur, database PostgreSQL terkelola Supabase, dan frontend React 19 dengan static export.
